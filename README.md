# OYLAB.kz — жаңартылған демо-нұсқа

## GitHub Pages-ке орналастыру
1. ZIP файлын компьютерге жүктеп, ішіндегі файлдарды шығарыңыз.
2. GitHub репозиторийін ашыңыз: https://github.com/nurgul81/OYLAB
3. Add file → Upload files таңдаңыз.
4. `index.html`, `style.css`, `script.js` файлдарын репозиторийдің негізгі бетіне (root) жүктеңіз. Ескі аттас файлдарды алмастырыңыз.
5. Commit changes басыңыз.
6. 1–3 минуттан кейін https://nurgul81.github.io/OYLAB/ бетін жаңартыңыз.

## Мұғалімге кіруді тексеру
Басты беттегі «Мұғалімге кіру» батырмасын басыңыз.
Демо құпиясөзі: `oylab2026`

## Маңызды шектеулер
- Бұл — демонстрациялық нұсқа.
- Тест нәтижелері тек сол браузердің `localStorage` қоймасында сақталады.
- Оқушы басқа телефоннан тапсырған нәтижені мұғалімнің басқа компьютерінен көру үшін Supabase немесе Firebase сияқты ортақ дерекқор мен қауіпсіз авторизацияны қосу керек.
- Демо құпиясөзі нақты қауіпсіздік құралы емес. Нақты оқушылардың жеке деректерін осы демо арқылы қорғалған деп есептемеңіз.
- Тест сұрақтары оқу мақсатындағы авторлық үлгі сұрақтар; ресми ҰБТ тапсырмалары емес.

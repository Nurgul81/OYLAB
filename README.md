# OYLAB.kz — демонстрациялық нұсқа 2

## Құрамында
- Қазақ тіліндегі басты бет
- Қонақ ретінде кіру: ашық оқу сауаттылығы демо тапсырмасы
- Оқушы және мұғалім кабинеттерінің интерфейсі
- Мұғалім панелінде 11 «Ә» және 28 оқушы құрылымы көрсетіледі
- Бір сұраққа автоматты кері байланыс

## Іске қосу
`index.html` файлын браузерде ашыңыз. Үш файл (`index.html`, `style.css`, `script.js`) бір папкада тұруы керек.

## Маңызды шектеу
Бұл — тек браузерде ашылатын фронтенд демонстрациясы. Кіру формасы нақты аккаунттарды тексермейді; оқушы деректері мен тест нәтижелері серверге сақталмайды. Мұғалім панеліндегі 28 оқушы — жобаның жоспарланған сынып құрамы, нақты тіркелген оқушылар тізімі емес.

Келесі іске асыру кезеңі: қауіпсіз авторизация, дерекқор, мұғалім/оқушы рөлдеріне арналған рұқсаттар және нәтижелерді серверде сақтау. `oylab.kz` домені де бөлек тіркеліп, хостингке бағытталуы қажет.

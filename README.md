# OYLAB.kz — жаңартылған демо-нұсқа

## Файлдар
- `index.html` — сайт құрылымы
- `style.css` — дизайн
- `script.js` — тест логикасы

## GitHub Pages-ке жүктеу
1. ZIP архивін компьютерге жүктеп, ішіндегі үш файлды шығарып алыңыз.
2. GitHub-та `nurgul81/OYLAB` репозиторийін ашыңыз.
3. `Add file` → `Upload files` батырмасын таңдаңыз.
4. Үш файлды (`index.html`, `style.css`, `script.js`) жүктеңіз.
5. `Commit changes` басыңыз.
6. Бірнеше минуттан кейін https://nurgul81.github.io/OYLAB/ сайтын жаңартыңыз.

## Демонстрациялық нұсқаның мүмкіндіктері
- Қазақ тіліндегі адаптивті дизайн
- Оқушының аты-жөнімен кіру (тіркелусіз)
- 10 сұрақтық авторлық оқу сауаттылығы тесті
- Автоматты балл есептеу және жауап түсіндірмелері
- Браузердің localStorage жадында тест тарихын сақтау
- Мұғалімге арналған қарапайым нәтижелер беті (демо пароль: `oylab2026`)
- Нәтижелерді CSV түрінде экспорттау

## Маңызды шектеу
Бұл — жұмыс істейтін браузерлік демо, бірақ серверлік дерекқор емес. Нәтижелер тек тест тапсырған құрылғының/браузердің жергілікті жадында сақталады. Басқа оқушының құрылғысынан мұғалімнің компьютеріне автоматты түрде жіберілмейді. 28 оқушының нәтижесін орталықтан жинау үшін Supabase/Firebase сияқты қорғалған backend, мұғалімнің қауіпсіз авторизациясы және деректерді қорғау баптаулары қажет. Мұғалім демо-құпиясөзі production үшін қауіпсіз емес.
